El sistema tendrá como objetivo permitir que un usuario registre y consulte tareas
pendientes.

Por el momento el proyecto solamente contiene su estructura inicial.
## Funcionalidades previstas
- Registrar tareas.
- Consultar tareas.
- Modificar tareas.
- Marcar tareas como terminadas.
## Control de versiones
Este proyecto utiliza Git para el control de versiones y GitHub como repositorio remoto.
